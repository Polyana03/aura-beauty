# Backend — Aura Beauty

Este diretório foi deixado de forma simples, para o 2º bimestre da disciplina.

## O que é usado aqui

- `db.json` — arquivo com os dados do projeto
- `json-server` — ferramenta que cria uma API rápida e fácil de usar

## Como executar

1. Instale as dependências:
   ```bash
   npm install
   ```

2. Inicie o servidor:
   ```bash
   npm start
   ```

3. Depois disso, a API vai ficar disponível em:
   ```bash
   http://localhost:3001
   ```

## Exemplo de rotas

- `GET /usuarios`
- `GET /profissionais`
- `GET /agendamentos`
- `POST /usuarios`
- `POST /profissionais`
- `POST /agendamentos`

## Observação

Essa é uma versão bem simples e fácil de entender, ideal para um estudante do ensino médio.
